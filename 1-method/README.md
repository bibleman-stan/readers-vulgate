# 1-method

Per-corpus canon: colometry rules, pericope rules, scholarly grounding, rules
audit. Public by decision — publishing Stan's own method canon is fine;
third-party licensed material is not.

**Empty so far.** The Vulgate reader has no per-corpus canon yet; its rules come
from `atu-method` and the UD_Latin-PROIEL substrate. This slot is claimed so the
shape is legible and the canon has somewhere to land when it is written.

Part of the five-tier reader shape: `1-method` (canon) · `2-evidence`
(measurements and retractions) · `3-project` (the handbook) · `4-process` (how
the work runs) · `5-machinery` (code). The served site — `books/`, `data/`,
`index.html`, `sw.js`, `CNAME` — stays unnumbered at the root, because GitHub
Pages serves from there and numbering it would break the live domain.
